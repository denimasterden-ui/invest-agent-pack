# Invest Agent — скилл-пак (v2)

Инструмент value-инвестинга в стиле Burry: не «дёшево/дорого», а **сигнал =
(цена vs Base) × (дрейф Base) × (тезис жив)**. Оценка мерой по типу бизнеса,
якорь на каждое число, отказ гейта = результат. Расчёты копятся в **центральном
каноне** (общий Postgres-стор), атрибуция по автору.

Начни с гида: скилл **`/ask-denis`** объясняет метод, призмы и как читать отказы.

## Что внутри

- **`.claude/skills/`** — скиллы:
  - `investagent-run` — прогон бумаги (профиль → призмы → Base → форки);
  - `investagent-show` — витрина канона (что накоплено, read-only);
  - `ask-denis` — гид по методу и маршрутизация;
  - `entry-timing` — тайминг входа (техника/объём/опционы vs 3 сценария);
  - `preipo-valuation` — оценка частной (pre-IPO) компании;
  - `md-to-pdf` — сборка PDF из markdown.
- **`invest-dashboard/agent/`** — движок: меры (`levered`/`ev_revenue`/`sotp`/
  `ddm_ri`), гейты полноты (свежесть, охват, контракт меры, **призмы**), форки,
  якоря. С эвалами (`agent/run_evals.py`).
- **`invest-dashboard/agent-run/`** — операторские обёртки (`ia`, collect_facts,
  collect_peers, gen_forks).
- **`invest-dashboard/knowledge/classifiers/book_prisms.md`** — 12 книжных призм
  (Graham, Fisher, Greenblatt, Marathon, Quality Investing…), из которых
  осознанно выбирается мера.

## Метод в двух строках

1. Собери инфу (факты + веб-ресёрч + свой разбор материала).
2. Прогони бумагу через **12 призм** → осознанно выбери меру (не роутер-дефолт).
3. Посчитай Base мерой из призм; тезисы о будущем — форками (ветки Base).
4. Гейты останавливают расчёт до числа и называют, что дособрать — **отказ это
   результат**, а не сбой.

## Старт

1. `SETUP.md` — поставь venv 3.12, задай окружение канона (`INVEST_MCP_URL` /
   `INVEST_AUTHOR` / `INVEST_TOKEN`), проверь эвалы.
2. В Claude Code открой этот репо, вызови `/ask-denis` — гид проведёт первый
   прогон.
3. Первый прогон: `/investagent-run ТИКЕР`.

## Границы

- Пак **считает и показывает**; ставку, рост и меру объявляет человек. Числа без
  якоря помечаются как НАБЛЮДЕНИЕ.
- Персонализированный инвест-совет пак не даёт — метод и числа, решение на
  человеке.
- v1-дашборд (Streamlit на Google Sheets), приватные тезисы и секреты автора в
  пак не входят.
