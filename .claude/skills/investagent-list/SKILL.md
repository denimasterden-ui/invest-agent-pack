# Скилл: ранжирование бумаг по IV15

Три вопроса, каждый со своим ответом: **что за угроза** (тир AICT), **сколько
она стоит** (IV15), **где бумага в ряду** (composite). Порядок обязателен —
тир задаёт допущения, из которых считается IV15.

Стандарты: `knowledge/iv15_standard.md` и `knowledge/classifiers/aict_tiers.md`.
Интерпретатор — `~/.venvs/invest312/bin/python`, из корня `invest-dashboard`.

**Решение за Денисом.** Скилл считает и показывает; рост, терминал и тир
объявляет он либо аналитик с названным признаком.

## Шаг 0 — прочитать накопленный опыт

```bash
ia findings --status open
```

## Шаг 1 — тир AICT

```bash
ia aict ТИКЕР --traits /tmp/ТИКЕР-traits.json
```

Признаки объявляет аналитик, прочитавший отчёт и звонки, — в автоисточнике их
нет и из отрасли они не выводятся. Словарь признаков печатает сама команда при
незнакомом ключе.

Рубрика печатает ЗА/ПРОТИВ по всем пяти тирам и не выбирает. **Ничья — это
результат:** соседние тиры разводит признак, который ещё не объявлен (чаще
всего `ai_native_uncertainty` между Fortress и Castle). Объявить его, а не
брать верхний.

Две угрозы держать раздельно: **замещение продукта** и **потеря seats**.
Переход на usage-based прайсинг отмечать фактом, но защитой не считать.

## Шаг 2 — IV15

```bash
ia iv15 ТИКЕР --net-income 730 --shares 58.6 \
  --growth 0.02x15 --terminal-growth 0.03 --r-terminal 0.115 \
  --price 134.90 --tier stone --roic 0.22
```

- `--growth` — стадии роста **прибыли владельца**, в сумме ровно 15 лет.
  Здесь работает тир: PAYC растёт выручкой ~12%, а её опубликованный IV15
  подразумевает ~2% на пятнадцать лет. Ставить компаундерскую траекторию
  Stone-бумаге — самая дорогая ошибка в этом расчёте (переоценка в 1.5+ раза).
- `--r-terminal` — требуемая доходность на **зрелом** бизнесе (9–12%), из неё
  выводится мультипликатор. 15% — барьер входа, не терминальная стоимость
  капитала. Называть мультипликатор напрямую (`--terminal-multiple`) — только
  с обоснованием.
- `--delta-e` — доля прибыли владельцу. Без неё берётся пул 83.4% **с явной
  пометкой**: строка помечается звёздочкой и её ранг не сравнивается наравне
  с посчитанными. Считать ΔE — шаг 4.
- Расхождение концов модели >50% — предупреждение: терминал несёт слишком
  много.

**Отрицательный IV15 — это результат.** Нет цены, дающей 15% годовых; бумага
не инвестируема и в ранжирование не идёт.

## Шаг 3 — список

```bash
ia list                 # весь канон, дорогие внизу
ia list --tier chapel   # внутри одного тира
```

Composite — инструмент **относительной** оценки внутри сопоставимой группы.
Сравнивать этим числом бумаги из разных отраслей нельзя: корзины не независимы,
а их состав по отраслям разный. Отсюда `--tier`.

Веса корзин (30/40/30) — **наши**, не Бьюри: он корзины называет, весов не
публикует. Не приписывать их ему в выводе.

## Шаг 4 — ΔE по 10-K (дорого, но это и есть ров)

Нужны за ~10 лет: `W` (выкуплено штук), `T` (потрачено), `C` (налог при
вестинге минус поступления от опционов), `ΔS` (изменение счёта акций).
Источники — Part II Item 5, сноска Share Repurchases, Consolidated Statements
of Shareholders' Equity.

Ловушки, каждая ловилась на живых данных:

- в `W` **не входят** акции, удержанные у сотрудника под его налог: они уже в
  `ΔS`, двойной счёт исказит всё;
- агрегаторы подставляют `C` вместо выкупа. У NVDA три года подряд
  «Cash (Repurchase) of Equity» — это был налог, выкупов не было;
- нет программы выкупа → `W=0`, `I=ΔS`, а цена берётся средней рыночной за год.

## Шаг 5 — записать урок

```bash
ia add-finding --category ... --title ... --body ...
```

## Сравнение с бумагой не из списка Бьюри

Ради этого всё и делается. Порядок тот же: тир → IV15 → `ia list --tier`.
Ответ звучит как «в своём тире бумага стоит N-й по composite при P/IV15 X×»,
а не «дешевле, чем MOH»: сравнение поперёк тиров и отраслей этим числом
не делается.

## Чего пока нет

- ΔE не автоматизируется и не будет: входы живут только в 10-K;
- composite не откалиброван против опубликованных баллов Бьюри — веса наши,
  сходится порядок, а не сами числа;
- IV15 пересчитывается вручную: цена меняется ежедневно, IV15 — нет.
