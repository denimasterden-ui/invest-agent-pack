# Скилл: Markdown → PDF

Превращает markdown-файл в стилизованный PDF. Путь: `.md` → встроенный HTML+CSS →
**headless Chrome `--print-to-pdf`**. Это де-факто наш способ — им сделаны
`clickhouse_thesis.pdf` и `plata_thesis.pdf` (Producer Skia/PDF). Без pandoc/LaTeX/pip.

## Окружение
- Скрипт: `.claude/skills/md-to-pdf/md2pdf.py` — только stdlib, зависимостей нет.
- Интерпретатор: **`/usr/bin/python3`** (любой подойдёт, модули не нужны).
- Нужен Google Chrome (`/Applications/Google Chrome.app`). Запускается headless,
  экран не трогает, временный профиль — не конфликтует с открытым Chrome.

## Запуск
```
/usr/bin/python3 ".claude/skills/md-to-pdf/md2pdf.py" ВХОД.md [ВЫХОД.pdf]
```
Без второго аргумента PDF кладётся рядом с `.md` (то же имя, `.pdf`). Команды — с
абсолютными путями (в пути рабочей папки есть пробел — кавычить обязательно).

## Шаги
1. Возьми путь к исходному `.md` (если Денис дал готовый markdown-текст без файла —
   сначала сохрани его в `.md`, потом конвертируй).
2. Запусти `md2pdf.py`. Скрипт печатает итог: `PDF: <путь> (<размер> KB)`.
3. **Проверь результат** (рендер картинки недоступен — нет poppler):
   ```
   file ВЫХОД.pdf      # должно быть "PDF document, N pages"
   ```
   Для самопроверки конвертера (таблицы/кириллица не поехали) можно прогнать
   `md2pdf.convert()` на исходнике и убедиться, что число `<table>` совпадает с
   числом таблиц в `.md`, а `'Тинькофф'/любое кириллич. слово` присутствует.
4. Сообщи Денису кликабельный путь к PDF и число страниц.

## Поддерживаемый markdown
`#`…`######` заголовки, `**bold**`, `` `code` ``, `[текст](url)`, таблицы
(`| … |` с строкой-разделителем `|---|`), маркированные/нумерованные списки,
`> цитаты`, `---` разделители, эмодзи. Этого хватает для тезисов и брифов в нашем
формате (как `clickhouse_thesis.md`). Картинки и вложенные списки — НЕ поддержаны;
если понадобятся, расширять `md2pdf.py`, а не обходить.

## Стиль
A4, поля 18/16 мм, системный шрифт (`-apple-system`), таблицы с зеброй и серой
шапкой, фирменно-сдержанно. Правки оформления — в константе `CSS` внутри `md2pdf.py`.
