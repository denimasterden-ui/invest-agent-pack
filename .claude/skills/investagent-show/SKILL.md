# Скилл: витрина канона (investagent-show)

Read-only просмотр центрального хранилища v2. Заменяет «зайти в `runs/` и
прочитать README» — вся раскладка теперь на сервере (UZ, Postgres-канон).
Ничего не считает и не пишет: только показывает накопленное.

## Окружение (канон-рантайм)

Как у investagent-run: venv 3.12 + `INVEST_MCP_URL`/`INVEST_AUTHOR`/`INVEST_TOKEN`
(см. `SETUP.md` в корне пака). Проще всего — через обёртку `ia` из корня пака:

```bash
IA=./invest-dashboard/agent-run/ia   # окружение уже в export (SETUP.md)
```

Без `INVEST_MCP_URL` — роестр пуст (центральный канон недоступен): проверь export.

## Роестр — все бумаги (без тикера)

```bash
$IA show
```

Печатает: сколько бумаг в каноне и сколько с прогонами; таблицу
`тикер · мера · версия · дата обновления · что накоплено` (baseline/форки/
материал с датами), свежие сверху; в конце — список бумаг «только профиль
(seed, без прогонов)». Так Денис видит, во что заходили недавно и где уже
есть оценка.

## Провалиться в бумагу (с тикером)

```bash
$IA show ТИКЕР
```

Инвентарь одной бумаги из канона: мера/версия/драйверы/сопоставимые/пробелы
профиля; последний baseline-коридор; активные форки (последний на лейбл,
старые поколения — в истории таблицы); разобранные материалы с авторами;
число точек дрейфа.

Флаг `--detail` — полная раскладка: допущения baseline (ставка/рост/fcf),
по каждому форку тезис + условия (must_be_true) + override'ы с якорями и
источниками, и **полный синтез материала** (что нашли в ресёрче):

```bash
$IA show ТИКЕР --detail
```

Для `sotp`/`ev_revenue` раскладка baseline разворачивает деривацию: выручка ядра,
терминал (FCF-маржа × множитель), рост, ставка, чистый кэш и доли-стейки.

Флаг `--explain` (включает `--detail`) — сверх раскладки просит **инвест-вывод
по трём осям** (цена vs baseline · дрейф · тезис жив/сломан), причёсанный через
`/humanizer`. Это анализ, не витрина: вывод показывается человеку, в канон **не
пишется**. Дефолтом держим лаконичный `show` — `--explain` вызывать осознанно.

```bash
$IA show ТИКЕР --explain
```

## Как отвечать

1. Нет тикера — покажи роестр, назови 2–3 самые свежие бумаги с прогонами.
2. Есть тикер — покажи инвентарь; если по нему пусто (только seed) — так и
   скажи и предложи прогон через скилл `investagent-run`.
3. Витрина не решает и не считает — за расчётами отсылай в investagent-run.
